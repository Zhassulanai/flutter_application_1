# Dota Stats — MVP Design Specification

**Дата:** 2026-05-10
**Автор:** Akhat (с Claude Code)
**Статус:** Draft → подлежит ревью пользователем
**Кодовое имя проекта:** `dota_stats`

---

## 1. Обзор

**Dota Stats (DS)** — мобильное приложение (Android + iOS) для просмотра статистики и истории игр в Dota 2.

### Цели
- Дать игроку быстрый и удобный доступ к подробной статистике своих матчей и матчей других игроков на смартфоне.
- Покрыть пробелы официального Steam API за счёт использования сторонних источников (OpenDota, Stratz).
- Сделать интерфейс **лёгким и не перегруженным**, с визуальной отсылкой к Dota 2, но без буквального копирования стиля игры.

### Аудитория
Русскоязычные и англоязычные игроки Dota 2, желающие отслеживать свою статистику, разбирать прошедшие матчи, смотреть статистику друзей и других игроков.

### Что НЕ входит в MVP
- Steam OpenID-вход (только ручной ввод ID в первой версии; OpenID — следующая версия)
- Полный справочник героев и предметов (только popup при тапе на предмет в матче)
- Графики статов по минутам (золото/опыт/урон)
- Push-уведомления о матчах друзей
- Лента про-матчей и турниров
- Сравнение игроков и героев между собой
- Мета-аналитика, тир-листы

## 2. Технологический стек

| Слой | Технология | Обоснование |
|---|---|---|
| Платформа | Flutter 3.x (Dart) | Один код для Android и iOS; пользователь уже работает с Flutter |
| State management | `flutter_bloc` | У пользователя уже есть опыт (использовался в Family chat) |
| HTTP-клиент | `dio` | Поддержка interceptors, retry, отмены, кэша; нужно для работы с тремя API |
| Локальное хранилище (кэш) | `hive` | Быстрый NoSQL-кэш для матчей и справочников |
| Защищённое хранилище (ключи API) | `flutter_secure_storage` | Keychain (iOS) / Keystore (Android) — стандарт для секретов |
| Простые настройки | `shared_preferences` | Тема, язык, выбранный профиль |
| Навигация | `go_router` | Официальный декларативный роутер от команды Flutter |
| Локализация | `flutter_localizations` + `intl` | Стандартный механизм Flutter, RU/EN |
| Иконки UI | `lucide_icons` | Современный, чистый, бесплатный набор |
| SVG | `flutter_svg` | Для логотипа и векторных изображений |
| Шрифты | `google_fonts` | Inter + JetBrains Mono без скачивания вручную |

### Архитектура: чистая архитектура (Clean Architecture)

```
lib/
├── core/          — общее: тема, константы, утилиты, сетевой клиент, кэш
├── data/          — модели, источники данных (API), репозитории
├── domain/        — (опционально для MVP, оставляем место)
├── presentation/  — экраны, виджеты, BLoC-и
└── l10n/          — переводы RU/EN
```

**Зачем такое разделение:** возможность подменить источник данных (например, добавить Stratz позже) или редизайн UI без переписывания других слоёв.

## 3. Источники данных (API)

### 3.1. OpenDota API — основной источник (~90% данных)
- **URL:** `https://api.opendota.com/api/`
- **Ключ:** не требуется для базовых запросов (60 запросов/мин)
- **Используется для:**
  - Профиль игрока: винрейт, ранг, аккаунт-инфо
  - История последних матчей
  - Подробности матча: 10 игроков, KDA, GPM/XPM, урон, лечение, крипы (last hits/denies), предметы, длительность, режим
  - Статистика по героям игрока
  - Поиск игрока по нику
  - Справочник героев и предметов (constants endpoints)

### 3.2. Steam Web API — для профиля Steam
- **URL:** `https://api.steampowered.com/`
- **Ключ:** требуется (бесплатно, получается за 2 минуты на `steamcommunity.com/dev/apikey`)
- **Используется для:**
  - Реальное имя в Steam, аватар в высоком качестве
  - Статус (онлайн / в игре / оффлайн)
  - Ссылка на публичный профиль
  - В будущем — Steam OpenID-вход (не в MVP)

### 3.3. Stratz API — углублённая аналитика
- **URL:** `https://api.stratz.com/graphql`
- **Ключ:** требуется (бесплатно, регистрация через Steam на `stratz.com`)
- **Используется в MVP минимально:**
  - Точное определение позиции/роли игрока в матче (тип GraphQL: `MatchPlayerType.position`)
- В следующих версиях — мета, фазы игры, продвинутая аналитика.

### 3.4. Хранение и онбординг ключей
- Ключи **никогда не хардкодятся в коде**.
- При первом запуске пользователь видит экран онбординга → пошаговая инструкция, как получить Steam API ключ и Stratz ключ (со скриншотами и ссылками).
- Ключи хранятся через `flutter_secure_storage`.
- Без ключей приложение работает **в ограниченном режиме**: только OpenDota (этого хватает для всей базовой статистики; нет только Steam-аватаров высокого разрешения и Stratz-данных о позициях).

### 3.5. Стратегия кэширования (Hive)

| Тип данных | TTL | Обоснование |
|---|---|---|
| Подробности матча | ∞ (навсегда) | Завершённый матч не меняется |
| Профиль игрока | 5 минут | Винрейт и ранг могут обновляться |
| Список последних матчей | 2 минуты | Новый матч появляется быстро после игры |
| Справочник героев | 7 дней | Меняется только с патчами |
| Справочник предметов | 7 дней | Меняется только с патчами |

### 3.6. Обработка ошибок API

| Ошибка | Реакция |
|---|---|
| Нет интернета | Показать кэш + плашка «Офлайн режим» |
| Запрос провалился (5xx, таймаут) | Auto-retry 3 раза с экспоненциальной задержкой, потом ошибка с кнопкой «Повторить» |
| Профиль приватный (Steam) | Объяснение «Откройте видимость матчей в настройках Dota 2» со скриншотом |
| Лимит API (429) | «Слишком много запросов, подождите минуту» |
| Игрок не найден | «Игрок с таким ID не найден. Проверьте правильность.» |

## 4. Экраны и навигация

### 4.1. Структура навигации
Нижняя панель с **3 вкладками**:

```
┌─────────────────────────────────┐
│         КОНТЕНТ ЭКРАНА          │
│                                 │
├─────────────────────────────────┤
│  👤 Профиль  🔍 Поиск  ⚙ Настройки │
└─────────────────────────────────┘
```

### 4.2. Список экранов MVP (6 штук)

#### 1. Онбординг (показывается один раз)
- Приветствие
- Выбор способа входа: «Войти через Steam» (отложено до v1.1) / «Ввести ID вручную»
- Опциональный экран ввода API-ключей (можно «Пропустить»)

#### 2. Профиль (главный экран после входа)
- **Шапка:** аватар, ник, медаль/ранг (Herald → Immortal), кнопка-шестерёнка → Настройки
- **Статистика:** всего игр, винрейт (круговой график), победы/поражения
- **Любимые герои:** топ-5 героев пользователя — иконка + игр + винрейт
- **Последние матчи:** компактный список из 10 (герой, win/lose, KDA, длительность, «как давно»). Тап → детали матча. Кнопка «Показать все» → история матчей.

#### 3. История матчей
- Полный список с пагинацией (по 20 матчей)
- Те же карточки, что на профиле
- Фильтры сверху: только победы / по герою / по режиму

#### 4. Детали матча (самый информативный экран)
- **Шапка:** Radiant vs Dire, счёт, длительность, режим, дата
- **Команда Radiant:** таблица из 5 игроков:
  - Иконка героя, ник, уровень
  - KDA
  - GPM / XPM
  - **Урон / Лечение / Крипы (last hits/denies)**
  - 6 предметов + backpack + neutral item
- **Команда Dire:** аналогично
- **Тап на героя в строке** → раскрывается подробная карточка (тайминг покупок предметов)
- **Тап на иконку предмета** → popup с описанием, рецептом, ценой
- **Тап на ник игрока** → его профиль

#### 5. Поиск игрока
- Поле поиска сверху (по нику или Steam ID/ссылке профиля)
- Результаты — список карточек: аватар, ник, последний матч, ранг
- История недавних поисков снизу
- Тап на результат → его профиль (без кнопки настроек, без «выйти»)

#### 6. Настройки
- Язык (RU / EN / Системный)
- Тема (Light / AMOLED / Системная)
- API-ключи: Steam Web API, Stratz (ввести / изменить / удалить)
- Аккаунт: выйти, сменить аккаунт
- О приложении: версия, ссылки на источники данных, GitHub

### 4.3. Анимации и UX-детали
- Стандартные iOS/Android переходы (slide для push, fade для табов)
- **Skeleton-загрузка** вместо спиннеров (серые анимированные заглушки формы карточек)
- **Pull-to-refresh** на профиле и истории матчей
- Минимальный размер тач-зоны 48×48 px (требование Android)

## 5. Дизайн и визуальный стиль

### 5.1. Темы
Две темы: **Light** и **AMOLED**. Переключатель в Настройках с тремя опциями: Light / AMOLED / Системная (светлая системная → Light, тёмная → AMOLED). По умолчанию: AMOLED.

#### Light палитра
| Назначение | Цвет |
|---|---|
| Фон | `#F5EFE0` (тёплый кремовый, «пергамент») |
| Карточки | `#FFFFFF` с лёгкой тенью |
| Основной текст | `#1A1A1A` |
| Вторичный текст | `#6B6B6B` |
| Акцент (золото Dota) | `#C8AA6E` |
| Победа / Radiant | `#3A8E3A` |
| Поражение / Dire | `#C13030` |
| Разделители | `#E5DFCF` |

#### AMOLED палитра
| Назначение | Цвет |
|---|---|
| Фон | `#000000` (чистый чёрный, OLED-friendly) |
| Карточки | `#000000` + рамка `#1F1F1F` (без заливки, только обводка) |
| Основной текст | `#F0E6D2` (тёплый белый из Dota UI) |
| Вторичный текст | `#7D7D7D` |
| Акцент (золото) | `#C8AA6E` |
| Победа / Radiant | `#5CBC4E` |
| Поражение / Dire | `#E04545` |
| Разделители | `#1F1F1F` |

#### Цвета медалей рангов (как в Dota 2)
Herald — серый, Guardian — бронза, Crusader — зелёный, Archon — фиолетовый, Legend — синий, Ancient — бирюзовый, Divine — розовый, Immortal — золотой градиент.

### 5.2. Шрифты
- **UI (заголовки, текст):** Inter (Google Fonts, поддержка кириллицы)
- **Цифры статистики (KDA, GPM, урон):** JetBrains Mono — моноширинный, чтобы цифры выравнивались колонками в таблицах матчей

### 5.3. Иконки и изображения
- **Иконки героев** — с CDN Steam (`cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/heroes/...`), не скачиваем в приложение
- **Иконки предметов** — оттуда же
- **UI-иконки** — `lucide_icons`
- **Логотип приложения «DS»** — кастомный SVG (см. раздел 5.5)

### 5.4. Переиспользуемые компоненты (`presentation/widgets/`)
| Компонент | Назначение |
|---|---|
| `StatCard` | Карточка с цифрой и подписью (винрейт, всего игр) |
| `MatchTile` | Строка истории матча (герой, результат, KDA, длительность) |
| `HeroAvatar` | Иконка героя с цветной рамкой команды (3 размера: S/M/L) |
| `ItemSlot` | Иконка предмета 32×32 с рамкой; тап → popup с описанием |
| `PlayerRow` | Строка таблицы игрока в матче (герой, ник, KDA, GPM/XPM, предметы) |
| `RankMedal` | Медаль ранга со звёздами, цвет по тиру |
| `SkeletonLoader` | Серая анимированная заглушка для загрузки |
| `SectionHeader` | Заголовок секции с золотой полоской слева |

### 5.5. Логотип «DS»
- **Стиль:** вдохновлён логотипом Dota 2 (два скрещенных клинка/зубца сверху, монограмма «DS» под ними) — узнаваемый, но **не нарушающий товарный знак Valve**
- **Цвет:** золотой `#C8AA6E` на тёмном `#0D0D0D` (приглушённая «тёмная» интерпретация)
- **Шрифт монограммы:** грубоватые «фэнтези»-засечки в духе игры
- **Формат:** SVG (масштабирование) + PNG 1024×1024 (требование App Store)
- **Где используется:** иконка приложения, сплеш-скрин, экран «О приложении»
- Файл генерируется как SVG-код в проекте; пользователь может заменить на собственный позже

### 5.6. Тонкие стилевые детали
- Скругления карточек: 8px (Material 3 стандарт, не «детские» круглые, не острые)
- Тонкие золотые разделители между секциями
- Лёгкий золотой glow вокруг важных кнопок при нажатии
- В шапке матча команды Radiant/Dire подсвечиваются их цветами
- Базовый отступ: 16px

## 6. Аутентификация и идентификация пользователя

### 6.1. Способы привязки аккаунта в MVP
- **Ручной ввод Steam ID или ссылки на профиль** (например, `https://steamcommunity.com/id/durka` или `76561198...` или Dota ID 32 бит)
- Утилита `steam_id_converter.dart` конвертирует между 32-битным (Dota ID) и 64-битным (Steam ID) форматами

### 6.2. Способы для будущих версий
- **Steam OpenID** (отложено в v1.1) — кнопка «Войти через Steam», открытие браузера, обработка redirect

### 6.3. Поддержка нескольких аккаунтов
В MVP — один активный профиль. Можно «выйти» и ввести другой ID. Профиль другого игрока через поиск отображается в read-only режиме.

## 9. Тестирование

**Цель покрытия:** ~60–70% кода (не 100% — это перфекционизм без пользы; главное — критичный путь).

### Unit-тесты (обязательны)
- Парсинг моделей из JSON OpenDota / Steam / Stratz
- Форматтеры: KDA, длительность, относительное время, числа с разделителями
- Конвертация Steam ID 32 ↔ 64 бит
- Репозитории с замоканными API-клиентами (`mocktail`)

### Widget-тесты
- Переиспользуемые компоненты: `StatCard`, `MatchTile`, `RankMedal`, `HeroAvatar`, `ItemSlot`
- Проверка: «при таких входных данных рисует ожидаемое»

### Integration-тесты
- Один сквозной поток: запуск → онбординг → ввод ID → отображение профиля

### Инструменты
- `flutter_test` (встроен)
- `bloc_test` (у пользователя уже подключен)
- `mocktail` (моки)

## 10. Этапы реализации (high-level)

Подробный план будет составлен следующим шагом (skill `writing-plans`).

1. **Фундамент:** создать проект, настроить темы (Light + AMOLED), роутер, локализацию
2. **API-слой:** Dio + три клиента + модели + репозитории + Hive-кэш + secure storage
3. **Онбординг:** экраны ручного ввода ID + инструкция по API-ключам
4. **Профиль:** главный экран с реальными данными OpenDota
5. **История матчей:** пагинация + фильтры
6. **Детали матча:** таблица 10 игроков, предметы с popup
