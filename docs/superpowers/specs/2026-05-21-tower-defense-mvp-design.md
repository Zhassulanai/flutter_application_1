# Tower Defense — Design Specification

**Date:** 2026-05-21
**Author:** Zhassulan Aitzhanov (with Claude)
**Status:** Approved for planning
**Target platforms:** Android, iOS (Play Store + App Store)

---

## 1. Видение

Минималистичный single-player Tower Defense с упором на OLED-эстетику (true black), тактическую глубину выбора башен и расслабляющую атмосферу. Игра — time-killer: можно играть одной рукой, в любой момент закрыть приложение и продолжить с того же места. **Без донатов, без рекламы, без pay-to-win** — игра должна быть честной и справедливой.

**Целевая аудитория:** игроки, любящие TD-классику (Element TD, Kingdom Rush, Bloons TD), которые ценят чистый дизайн, стратегическую глубину и спокойную игру без давления.

**Референсы:**
- Element TD, Warcraft III TD maps — система башен и maze-механика
- Kingdom Rush, Bloons TD 6 — мобильный UX, система звёзд
- GRIS, Geometry Wars — визуальный стиль и минимализм

## 2. Ключевые игровые решения

| # | Решение |
|---|---|
| 1 | **Перспектива:** Top-down 2D, неоновый минимализм на чёрном фоне (OLED-friendly) |
| 2 | **Карта:** гибрид — фикс-дорожки на ранних уровнях, maze (открытое поле с A*) на поздних |
| 3 | **Башни:** 5 типов × 2 ветки апгрейдов (5 уровней каждая). Общий бюджет на башню — 7 очков (можно 5+2, 4+3, 3+3) |
| 4 | **Экономика:** золото за киллы (сразу) + пассивный доход (в начале волны) + фермы (тик 1сек) + бонус за чистую волну |
| 5 | **Жизни:** Campaign — 20 жизней + 3 звезды по результату; Endless — выживание (рекорд = номер последней волны) |
| 6 | **Мета-прогрессия:** разблокировка контента (башни, ветки, карты) + слабые таланты (≤ 3-5%); баланс под игрока без талантов |
| 7 | **Темп:** адаптивная длина (5-15 мин/уровень) + save-and-resume в любой момент |
| 8 | **Сеттинг:** абстрактный геометрический; всё рисуется кодом (без художника) |
| 9 | **Управление:** портретная ориентация, играется одной рукой |
| 10 | **Сохранение:** локальное (Hive) → Google Play Games / Game Center перед релизом |
| 11 | **Стек:** Flutter + Flame |
| 12 | **MVP:** Lean (5 башен, 10 уровней, ~2-3 мес) → Balanced (20 уровней, таланты, ачивки, облако) перед релизом |

## 3. Архитектура

Pragmatic подход — модули по фичам, без формальной clean architecture. Цель — скорость разработки и поддерживаемость для соло-проекта.

### 3.1. Структура проекта

```
lib/
├── main.dart               // точка входа, инициализация Riverpod, роутинг
├── app.dart                // MaterialApp, тема, навигация
│
├── game/                   // Flame-часть (живой матч)
│   ├── td_game.dart        // главный FlameGame класс
│   ├── components/         // башни, враги, снаряды, путь, клетки
│   ├── waves/              // система волн, генерация врагов
│   ├── pathfinding/        // A* для maze, фикс-маршруты
│   └── effects/            // частицы, glow, неон-эффекты
│
├── meta/                   // мета-состояние вне матча
│   ├── profile/            // профиль, звёзды, открытый контент, таланты
│   ├── progress/           // прогресс уровней, рекорды Endless
│   └── unlocks/            // система разблокировок
│
├── ui/                     // Flutter-экраны вне матча
│   ├── main_menu/
│   ├── level_select/
│   ├── talents/
│   ├── settings/
│   └── shared/             // переиспользуемые виджеты
│
├── data/                   // данные и сохранения
│   ├── configs/            // JSON: уровни, башни, враги, волны, таланты
│   ├── repositories/
│   ├── local_storage.dart  // Hive
│   └── cloud_sync.dart     // Play Games / Game Center (этап B)
│
└── core/
    ├── theme/              // цвета, шрифты, OLED-палитра
    ├── audio/              // SFX и музыка
    └── util/
```

### 3.2. Зависимости

- `flame` — игровой движок
- `flutter_riverpod` — управление состоянием
- `hive` + `hive_flutter` — локальное хранение
- `flame_audio` + `audioplayers` — звук
- `flutter_localizations` + `intl` — локализация
- `google_play_games_services` + `game_services` — облачное сохранение (этап B)
- `firebase_crashlytics` — краш-репортинг (этап B)

### 3.3. Главный принцип разделения

- **Flame** знает только про текущий матч (компоненты, рендеринг, физика, тач).
- **Flutter** отвечает за всё вне матча: меню, прогрессия, настройки, локализация.
- **Riverpod** хранит общее состояние (PlayerProfile, текущая MatchState) — доступен и из Flutter, и из Flame.

## 4. Модель данных

### 4.1. Внутриигровые сущности (Flame, живут только во время матча)

```
Tower
  id: уникальный
  type: enum (BasicShot, Splash, Sniper, Slow, Farm)
  position: Vector2 (клетка сетки)
  branchAPoints: 0..5
  branchBPoints: 0..5
  totalBudget: 7
  damage / range / fireRate / спец. эффекты (вычисляются из веток)
  killCount, totalDamage (статистика)

Enemy
  type: enum (Grunt, Fast, Tank, Swarm, Boss)
  hp, maxHp, speed
  position: Vector2
  pathProgress: 0..1
  immunities / resistances (optional)
  bounty: int (золото за килл, выплачивается сразу)
  damageToBase: 1..10

Projectile
  source, target, damage, speed, спец. эффекты

Wave
  index
  spawn schedule: List<{ enemyType, count, delay }>
  bonusGoldForClean: int
```

### 4.2. MatchState (Riverpod, сериализуется в Hive для save-and-resume)

```
MatchState
  levelId | endlessSeed
  currentWave / totalWaves
  lives                      // 20 в Campaign
  gold
  income                     // пассивный, отображается, выплачивается в начале волны
  farmsIncome                // от ферм, капает каждую секунду (тик 1с)
  towers: List<Tower>
  enemies: List<Enemy>
  paused / waveInProgress / gameOver
  speed: 1x | 2x | 3x
  cleanWavesCount
```

> **Замечание про экономику:** золото за киллы поступает мгновенно. `income` (пассивный) показывается на UI как "приход с волны" и выплачивается в начале каждой новой волны. `fermsIncome` тикает каждую секунду во время матча. Бонус за чистую волну добавляется отдельно при завершении волны без потерь.

### 4.3. PlayerProfile (Hive, постоянное хранение)

```
PlayerProfile
  unlockedTowers: Set<TowerType>
  unlockedBranches: Set<(TowerType, branchId)>
  unlockedLevels: Set<int>
  levelStars: Map<levelId, 0..3>
  endlessHighScores: Map<mapId, int waves>
  talents: Map<talentId, level>
  totalStars: int            // валюта для покупки талантов
  settings: { sfxVolume, musicVolume, lang, hapticOn, reduceEffects }
```

### 4.4. Конфиги (JSON в assets/configs)

```
levels/01.json   // mapId, fixedPath|maze, gridSize, entry/exits, waves, starThresholds
towers.json      // per-type статы и обе ветки апгрейдов с эффектами
enemies.json     // per-type статы, скейл по волнам
talents.json     // список талантов, стоимости в звёздах, эффекты
```

### 4.5. Хранилища (Hive boxes)

- `profile` — одна запись PlayerProfile
- `saved_match` — текущая прерванная сессия (одна запись или пусто)
- На этапе B: облачный JSON-снимок профиля синхронизируется при значимых изменениях

## 5. Правила геймплея

### 5.1. Башни (5 типов на Lean MVP)

| Тип | Форма / цвет | Базовая роль | Ветка A | Ветка B |
|---|---|---|---|---|
| **Basic Shot** | круг, cyan | одиночная цель, средний DPS | дальность + скорострельность | критический урон |
| **Splash** | треугольник, magenta | AOE-урон | радиус взрыва | поджигает (DoT) |
| **Sniper** | ромб, yellow | большой урон, медленно | пробивание брони | цепная молния |
| **Slow** | кольцо, purple | замедление врагов | заморозка (стан) | aura замедления вокруг |
| **Farm** | квадрат, green | не атакует, генерит золото/сек | больше дохода | дешёвая постройка |

Бюджет на башню: 7 очков. Можно 5+2, 4+3, 3+3 и т.д.

### 5.2. Враги (4 + 1 босс на Lean MVP)

| Тип | HP | Скорость | Особенность |
|---|---|---|---|
| **Grunt** | средне | средне | базовый |
| **Fast** | мало | высоко | трудно попасть |
| **Tank** | много | низко | броня — снижает урон |
| **Swarm** | очень мало | средне | приходят пачкой |
| **Boss** | очень много | низко | в конце акта, иммунитет к замедлению |

### 5.3. Волны

- 10–15 волн на уровень в Campaign
- Между волнами — пауза, можно строить/апгрейдить
- Кнопка READY ускоряет начало волны и даёт небольшой бонус золота
- Каждая 5-я волна — elite (усиленные)
- Последняя волна акта — босс

### 5.4. Экономика (стартовые значения, докрутим после тестов)

- Стартовое золото: 100
- Пассивный доход: 10 в начале первой волны (+2 на каждую следующую)
- Бонус за чистую волну (без потерь жизней): +20 + (wave × 2)
- Бонус за READY: +5
- Доход с фермы: 5 золота/сек (база), 8/сек (ветка A "доход"); стоимость 60 (15 в ветке B "дёшево")
- Цены башен: 50 / 80 / 120 / 150 / 60 (Basic / Splash / Sniper / Slow / Farm)
- Продажа: 70% потраченного на башню

### 5.5. Условия победы / поражения

- **Победа:** пройдены все волны уровня, lives > 0
- **Поражение:** lives = 0
- **Звёзды (Campaign):**
  - ★★★ — потеряно 0 жизней
  - ★★ — потеряно 1–6 жизней
  - ★ — пройден с любым результатом
- **Endless:** рекорд = номер последней пройденной волны

### 5.6. Pathfinding

- **Фикс-маршруты:** точки пути в JSON-конфиге, враги идут строго по ним
- **Maze:** A* по сетке. Перед постройкой башни — проверка "не блокирует ли единственный путь". Если блокирует — постройка запрещена. Враги пересчитывают маршрут при изменении карты (новая башня / продажа).

### 5.7. Скорость и пауза

- 1×, 2×, 3× — `dt × speed`
- Пауза — `dt = 0`, оверлей с Resume / Restart / Quit
- Выбранная скорость запоминается между матчами

### 5.8. Save-and-resume

- При уходе приложения в background (`AppLifecycleState.paused`) — сериализуем `MatchState` в Hive box `saved_match`
- При следующем запуске на главном меню: вместо "Play" — кнопка "Continue"
- При завершении матча — saved_match удаляется

## 6. UI / UX

### 6.1. Стилевые принципы (OLED-first)

- **Фон везде #000** — true black (пиксели OLED полностью выключены)
- **Границы панелей** — тонкие неоновые линии 1px
- **Активные элементы** светятся через `BoxShadow` / glow
- **Цвета по смыслу:**
  - cyan (#00d4ff) — выбор, информация, Basic Shot
  - magenta (#ff6b9d) — Splash башня, акценты
  - yellow (#ffd93d) — золото, Sniper
  - purple (#9d4edd) — Slow башня, таланты
  - green (#44ffaa) — фермы, доход
  - red (#ff3b3b) — жизни, опасность
- **Шрифт:** monospace для чисел/HUD, sans-serif для меню
- **Никаких градиентов, заливок панелей** — только border + glow

### 6.2. Список экранов

1. **Splash** — лого, асинхронная загрузка профиля и конфигов
2. **Main Menu** — Continue (если saved match) / Campaign / Endless / Talents / Settings
3. **Level Select** — список уровней со звёздами, заблокированные = серые
4. **Endless Map Select** — выбор карты для Endless
5. **In-Match** — игровой экран (см. 6.3)
6. **Pause / Game Over / Victory** — оверлеи поверх матча
7. **Talents** — дерево талантов, тратишь звёзды
8. **Settings** — звук, музыка, вибрация, язык, "о игре"

### 6.3. Главный экран матча

- **Верхняя панель:** Wave / Lives / Gold / Pause (всё под большой палец)
- **Карта** занимает ~60% экрана
- **Тап на пустую клетку** → подсветка зоны → выбор башни из палитры внизу
- **Тап на башню** → подсветка радиуса + панель апгрейдов с двумя ветками и общим бюджетом
- **NEXT:** показывает следующих врагов; **READY** — ускоряет старт волны
- **Speed control:** 1× / 2× / 3× снизу

### 6.4. Управление

- Только портретная ориентация (заблокирована)
- Поддержка экранов 16:9 — 21:9
- SafeArea для notch / dynamic island
- Все интерактивные элементы — крупные тап-зоны под большой палец

## 7. Аудио и тактильная отдача

### 7.1. SFX (10–15 на Lean MVP)

- Постройка башни, апгрейд, выстрелы по типам, попадание, килл, босс убит, потеря жизни, победа, поражение, UI tap. Звуки могут редактироваться после тестов.

### 7.2. Музыка

- **Жанры:** ambient, chillout, chillstep с лёгкими битами
- **Настроение:** спокойное, расслабляющее, медитативное — даже в Endless. Не давить на игрока
- 1 трек для меню (самый мягкий)
- 2-3 трека для боя в Campaign (по актам)
- 1 трек для Endless (становится плотнее по слоям с волнами, но в чилл-зоне)
- Раздельные слайдеры громкости музыки и SFX в настройках

### 7.3. Haptic feedback

- Лёгкий tick — тап на кнопку
- Средний impact — постройка башни
- Сильный impact — потеря жизни
- Сильный impact + длинная вибрация — поражение
- Тогглится в настройках (по умолчанию on)
- Реализация: `HapticFeedback.lightImpact()` и т.п.

### 7.4. Источники аудио

Бесплатные библиотеки (Freesound, OpenGameArt, ZapSplat free-tier) + генерация sfxr-подобными инструментами.

## 8. Локализация и поддержка платформ

### 8.1. Языки (все 3 с релиза)

1. **Английский** (default для всех неподдерживаемых локалей)
2. **Казахский**
3. **Русский**

Реализация: `flutter_localizations` + `intl` + `.arb` файлы. Ни одна строка не хардкодится.

Перевод: через AI (Claude) с вычиткой и редактурой автором.

### 8.2. Платформы

- **Android:** мин. версия 7.0 (API 24), покрывает 95%+ устройств
- **iOS:** мин. версия 13 (требование Flutter)
- Тестовые устройства: личный Android + симулятор iOS. Финальная iOS-сборка через Mac или Codemagic — обсуждается перед релизом.

### 8.3. Производительность

- Целевой FPS: 60 на средних устройствах
- Узкие места для мониторинга: частицы, одновременные снаряды, A* на больших maze
- Настройка "Reduce effects" для бюджетных устройств

### 8.4. Permissions

- Lean MVP — полностью offline, никаких permissions
- Этап B — интернет (опционально) для облачного сохранения и лидербордов; игра работает без них

### 8.5. Аналитика и крашлог (этап B)

- Firebase Crashlytics
- Минимальная аналитика без персональных данных: какие уровни проходят, где умирают, какие башни популярны — для балансировки

### 8.6. Монетизация

**Без донатов, без рекламы, без микротранзакций.** Игра либо полностью бесплатна, либо платная разовая (решение перед релизом). Этот принцип закреплён.

## 11. Принципы, которые НЕ нарушаем

1. **Без донатов и рекламы** — навсегда
2. **Честный баланс** — уровни проходимы без талантов
3. **OLED-first** — фон всегда #000
4. **Save-and-resume** — игрок никогда не теряет матч
5. **Спокойная атмосфера** — музыка и темп не должны давить
6. **YAGNI** — не добавляем фичи "на будущее", только то, что нужно сейчас
